## Requirements

- **Node.js** 18.0.0 or later (compatible with Bun, Deno, and modern browser environments)
- **TypeScript** 5.5 or later with `strict` mode enabled

### Compatibility rationale

- **Node.js Runtime Compatibility**: Built-in runtime feature detection provides zero-dependency fallbacks for newer ECMAScript features (such as `Set.prototype.union` and `Array.prototype.toSorted`), while `Intl.Segmenter` is loaded lazily for `Str.graphemeSize`, allowing `@pplnd/core` to run on Node.js 18+ and all modern JS runtimes.
- **TypeScript 5.5+**: Required because the ECMAScript 2024 Set methods (`.union()`, `.intersection()`, `.isSubsetOf()`) were introduced into TypeScript's standard library (`lib.es2024`) in version 5.5; the ECMAScript 2023 Array copying methods (`.toSorted()`, `.toReversed()`) entered the standard library (`lib.es2023`) earlier, in version 5.2.
- **Strict Mode**: Required for type-level guarantees — specifically exhaustiveness checking in `match` pattern branches and narrowing in type guards.

## Importing from `@pplnd/core`

`@pplnd/core` exposes a single entry point. Everything is imported directly from the root package:

```ts
import { Arr, Maybe, pipe, Result, Task } from "@pplnd/core";
```
